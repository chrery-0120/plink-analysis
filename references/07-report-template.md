# 报告模板（07-report-template）

> **适用场景**：流水线每个阶段生成 `report.md`、最终生成 `final_report.md/.html`，以及向用户口头/文字汇报时使用。目标是让"不太懂 PLINK 的分析人员"能直接读懂结论与依据，让"会加载文档的 AI agent"能按固定字段抽取数字。所有数字必须来自 `metrics.json`/`tables/*.csv`，不允许手写估计值。

## 0. 通用写作规范

1. **语言**：正文中文；专业术语保留英文（GWAS、PCA、λGC、ROH、FROH、FST、PI_HAT、MAF、HWE、LD、clump、lead SNP）。首次出现给中文解释。
2. **结论先行**：每段第一句是结论（PASS/WARN/FAIL 或"发现 X"），随后才是数字与依据。
3. **数字规范**：p 值保留 2–3 位有效数字（`1.2e-9`）；λ 保留 2 位小数；比例保留 1 位小数并给分子/分母（`390/400 = 97.5%`）；效应量给单位与 A1；坐标给基因组版本。
4. **判定用语**：`PASS`（达标）、`WARN`（可继续但需注意）、`FAIL`（不可用于后续结论）。禁止用"基本没问题""应该可信"这类模糊表述。
5. **可追溯**：每个参数写来源（config 键或命令行），每个阈值写依据（PLINK 默认 / 文献 / 本群体校准），每个图写文件名。
6. **不夸大**：相关不等于因果；发现集结果不等于验证；未做混合模型必须写明；校准没覆盖到的范围要写"未覆盖"。
7. **报告结构固定**：阶段报告 7 段，最终报告 9 段；顺序不要随阶段变化。

## 1. 阶段报告模板（每阶段固定 7 段）

```markdown
# 阶段 <编号> <名称> 报告

- run_id：<run_id>
- 阶段状态：PASS / WARN / FAIL / SKIPPED
- 生成时间：<ISO 时间>
- 输入：<文件/prefix + sha256>
- 输出：<产物清单>

## 1. 目的
<本阶段要回答的问题，2–4 句。例：把原始 VCF 转成 PLINK 二进制并确认数据完整性，为后续质控提供可信输入。>

## 2. 方法与参数
<软件与版本、命令（可折叠代码块）、关键参数表。参数表列：参数 | 取值 | 来源/依据。>

## 3. 结果
<表格 + 图。表格必须有表头与单位；图用相对路径 `plots/xx.png`。>

## 4. 质控判定
| 检查项 | 结果 | 阈值 | 判定 |
|---|---|---|---|
| ... | ... | ... | PASS/WARN/FAIL |

## 5. 异常与处理
<发现的异常、原因、采取的动作（含被剔除的样本/位点数与 ID 清单文件）。若无需处理，写"未发现异常"。>

## 6. 对后续/结论的影响
<本阶段结果如何影响下一阶段；WARN/FAIL 的限制如何传递到最终报告。>

## 7. 产物清单
| 文件 | 说明 |
|---|---|
| tables/xx.csv | ... |
| plots/xx.png | ... |
| metrics.json | 本阶段指标（机器可读） |
```

### 1.1 各阶段必填内容

| 阶段 | 第 3 节必须包含 | 第 4 节判定项 | 第 6 节必须说明 |
|---|---|---|---|
| intake | 格式、样本数、位点数、染色体集合、物种推断、表型/协变量概况、preflight 检查表 | 文件完整性、编码合法性、ID 唯一性、表型编码 | 数据规模是否足以支撑后续分析；需要用户确认的假设（物种、染色体集、表型类型） |
| qc | 前后计数、各原因剔除数、缺失率/MAF/HWE/杂合度分布、PI_HAT 分布、性别核查、PCA 离群 | 保留率、缺失率、HWE 极值比例、性别不一致、重复/近亲处理 | 样本量/位点数下降对 power 与群体参数稳定性的影响；未删近亲的理由 |
| popgen | PCA 方差解释、离群；PI_HAT>0.25 配对数与最大值；LD 衰减分箱表；ROH/FROH 汇总与 top 样本；FST 全局与两两矩阵；杂合度/近交 | 剪枝是否执行、离群是否处理、LD/ROH 参数是否适配物种、FST 分组是否 ≥2 | PC 是否进入 GWAS 协变量、亲缘是否需混合模型、保种/育种解释的边界 |
| gwas | 模型与协变量、M、λ、QQ、Manhattan、Bonferroni/1/M/FDR 阈值、显著位点数、lead SNP 表、clump 表 | 表型/编码、协变量、λ 范围、显著位点是否可解释、clump 参数 | 结果是否为发现集、是否需验证、是否需要 LMM、效应量是否受 winner's curse 影响 |
| calibration | 零模型 λ 分布与经验错误率、QTL power/偏差/AUC、validation 检查表 | λ 均值、经验 α、power 与解析预期、β/SE 校准、validation 全通过 | 流水线可信范围与未覆盖范围；5e-8 结论的谨慎程度 |
| report | 汇总表、图清单、最终判定 | 各阶段状态汇总 | 总体结论与局限 |

## 2. 最终报告模板

```markdown
# <项目名> 全基因组分析报告

- run_id / 生成时间 / 软件版本（PLINK 1.9.0 64-bit、Python 版本）
- 数据：<基因型来源> + <表型来源>
- 一句话结论：<数据质量是否达标；是否发现显著关联；结论的可信边界>

## 摘要（5–8 句）
1. 数据规模与物种：<n 样本、m 位点、芯片/重测序、品种>。
2. 质控：保留 <x> 样本（<%>）、<y> 位点（<%>），主要剔除原因 <...>。
3. 群体结构：前 2 个 PC 解释 <..>%；识别 <k> 个亚群/品种；<n> 对高亲缘。
4. GWAS：<模型>，协变量 <...>，λ=<..>；<n> 个位点达 Bonferroni，<m> 个达 FDR 0.05；最强信号 <SNP>（p=…，效应量…）。
5. 校准：零模型 λ=<..>（10 次重复），经验 α=0.05 → <..>；已知 QTL power/排名 <...>；独立重算 <n>/<n> 通过。
6. 结论与限制：<可下什么结论、不能下什么结论、建议的验证/后续分析>。

## 1. 数据概况
- 来源、格式、样本数、位点数、染色体集合与物种（猪 18/牛 29/羊 26/鸡 38…）
- 表型类型与分布（数量/二元；缺失率；病例比例）
- 协变量清单与来源
- 芯片密度/测序深度；基因组版本
- 文件清单与 sha256（可放附录）

## 2. 质控
- 阈值表（参数、取值、依据、config 键）
- 过滤前后计数表（样本、位点；按原因分解）
- 关键图：缺失率、MAF 谱、HWE QQ、杂合度分布、性别核查、PI_HAT 直方图
- 判定：PASS/WARN/FAIL + 理由
- 处理记录：删除/保留的样本与位点清单文件路径

## 3. 群体结构与亲缘
- PCA：剪枝参数、PC 数、方差解释率、离群（图 + ID）
- 亲缘：PI_HAT 分布、>0.25 配对数、重复样本处理
- LD 衰减：分箱表与图、r²=0.2 的距离
- ROH/FROH：参数（随物种调整）、FROH 分布、top 个体、长度分箱
- FST：分组方式、全局均值（原始/加权）、两两矩阵、top 位点
- 多样性：Ho/He/FIS（若计算）、近交系数
- 解释边界：小群体/品种混合/芯片密度的限制

## 4. GWAS
- 模型与选择依据（数量性状 `--linear`、二元 `--logistic`）
- 协变量清单（PC 个数、性别、批次、品种）与缺失处理
- 检验位点数 M、λGC、QQ 图、Manhattan 图
- 多重检验阈值表（Bonferroni、1/M、FDR 0.05）
- 显著位点表（SNP、CHR:BP、A1/A2、AF、BETA/OR、SE/CI、p、N）
- clump 表（index SNP、区间、位点数、p 范围、参数）
- 条件分析/敏感性分析（若做）
- 解释：效应方向、候选基因（若有注释）、与文献比较、winner's curse 提示

## 5. 校准与独立校验
- 零模型：R、λ 均值/SD、经验 α（0.05/1e-3/5e-8）、QQ
- 已知 QTL：h2、因果位点数、power、β 偏差、SE 校准、top100/AUC
- 独立重算：14 项检查表、容差、最大偏差
- 结论：流水线在当前规模下是否可信；未覆盖范围

## 6. 方法
- 软件与版本、参考基因组、芯片/测序平台
- 完整命令（或指向 logs/commands.jsonl）
- 关键参数表（QC、popgen、GWAS、calibration）
- 统计方法：λGC 定义、Bonferroni/FDR、PI_HAT、FST 估计、FROH 定义与分母
- 引用：PLINK 1.9（Chang 2015；Purcell 2007）、Anderson 2010、Wigginton 2005、Weir & Cockerham 1984、Yang 2011 等

## 7. 复现
- run.json（输入、配置、环境冻结）
- commands.jsonl（每次 PLINK 调用的完整命令、耗时、返回码）
- 随机种子（仿真、子集抽样、PCA 近似）
- 目录结构与产物说明
- 一键复现命令（`python plink_pipeline.py run --run-dir <dir>`）

## 8. 局限与建议
- 样本量/芯片密度导致的 power 限制
- PLINK 1.9 无混合模型；家系结构可能使 p 值偏乐观
- 群体结构/批次与表型混杂无法完全校正
- 发现集无独立验证；效应量有 winner's curse
- 畜禽参考基因组/芯片版本差异；家禽 ZW 的特殊性
- 建议的后续实验/分析（更大群体、imputation、LMM、功能验证）

## 附录
- 图清单、表清单、样本/位点剔除清单、文件 sha256、术语表
```

## 3. 给用户的分段汇报话术（每段 5–10 行）

规则：**先结论、后数字、再限制**；一段只讲一个阶段；不堆术语；每个数字都能在报告里找到出处。CLI 同时输出单行 `SUMMARY_JSON: {...}` 供 agent 解析，`SUMMARY_MD` 供人读（DESIGN 第 11 节）。

### 3.1 数据接入

> 已识别输入为 <bed/VCF/ped/…>，共 <n> 个样本、<m> 个位点，染色体集合与 <物种> 一致（<18/29/26/38> 对常染色体 + X…），表型为 <数量/二元>，缺失 <x>%。预检 <通过/有 N 项需确认>：<编码/ID/表型编码>。接下来进入质控；如果物种或表型类型判断有误，请现在告诉我，以免后续阈值用错。

### 3.2 质控

> 质控后保留 <390/400> 个样本（97.5%）和 <6500/8000> 个位点（81.3%）。主要剔除原因：位点缺失率 <300>、MAF <800>、HWE <400>；样本缺失率 <2>、杂合度离群 <1>、重复样本 <1>、性别不一致 <0>。判定 <PASS>。需要说明的是：<未删除近亲样本，因为该群体为家系结构，将在 GWAS 阶段用模型解释>。样本量下降对 power 的影响会在最终报告中量化。

### 3.3 群体结构

> PCA 前两个主成分解释 <5.2%> 和 <3.1%> 的方差，样本按 <品种/场次> 聚成 <2> 组，未发现需要剔除的离群样本。PI_HAT>0.25 的配对 <5> 对，最大 <0.51>（<半同胞>），已保留并在 GWAS 中说明。LD 衰减：r²=0.2 的距离约 <120 kb>。FROH 均值 <0.05>，最高个体 <0.21>。FST（<品种间>）全局 <0.08>。这些结果说明群体结构<明显/较弱>，GWAS 需要 <PC1–5 + 品种> 作为协变量。

### 3.4 GWAS

> 用 <--linear> 模型、协变量 <PC1–5、性别、批次> 对 <性状> 做关联，检验 <6400> 个位点。λGC=<1.01>（在预期波动内），QQ 图<尾部有偏离/整体贴合>。Bonferroni 阈值 <7.8e-6>，<3> 个位点显著；FDR 0.05 下 <12> 个。最强信号 <rs2>（<1:1.2Mb>，p=<1.2e-9>，A1=<A>，BETA=<0.42>，SE=<0.07>），clump 后得到 <2> 个独立信号。提示：<样本量有限，效应量可能存在高估；建议在独立群体验证>。

### 3.5 校准

> 零模型重复 <10> 次，λGC 均值 <1.00>（SD <0.03>，理论 <0.03>），α=0.05 的经验假阳性率 <5.1%>，5e-8 水平未出现假阳性（预期 <0.01> 个，不能据此精确估计错误率）。已知 QTL（h2=<0.5>，<20> 个因果位点）仿真中 <95%> 的因果位点进入 top100，rank AUC=<0.97>，β 偏差 <+2%>，SE 校准比 <0.98>。独立重算 <14> 项全部通过。结论：当前数据规模下流水线的检验统计量校准良好；全基因组显著性结论仍受样本量限制。

### 3.6 最终汇报（3–6 句）

> 本次分析共 <390> 个样本、<6500> 个位点通过质控；群体结构<中等>，已用 <PC1–5> 校正；GWAS 发现 <3> 个 Bonferroni 显著位点（最强 <rs2>，p=<1.2e-9>），<12> 个 FDR 0.05 位点；校准与独立重算均通过，λ=<1.01>。主要限制是<样本量/无混合模型/无独立验证>，建议<扩大群体或独立验证/用 GCTA 或 SAIGE 复核>。详细依据见报告第 <4> 节与附件。

## 4. 措辞与合规清单

- 用"关联/信号/候选位点"，不用"致病位点/因果位点"（除非有功能证据）；用"在发现集中达到全基因组显著"，不用"证明该基因影响性状"。
- 效应量必须带方向与单位：`BETA=0.42（表型单位/A1 拷贝）`、`OR=1.35（A1 vs A2）`；未做混合模型时写"p 值可能偏乐观"，未做独立验证时写"效应量可能高估"。
- 小群体/保种结论要写"抽样不确定性大，建议多世代/多年度重复"。
- 家禽 ZW 写"性染色体未按 XY 模型分析，Z 染色体结果单独解释"。
- 引用阈值来源（PLINK 默认、文献、本群体校准），不写"经验值"了事。
- 图内标签用英文（字体兼容），中文解释放正文（DESIGN 第 10 节）；HTML 报告必须自包含（图片 base64 内嵌、CSS 内联）。

## 5. 常见误区 / 检查清单

- [ ] 每段是否"结论先行"？读者能否只看每段第一句就抓住要点？
- [ ] 每个数字是否能在 `metrics.json`/`tables/*.csv` 中找到？有没有手写或口算的数字？样本/位点计数是否守恒（in − removed = out）？
- [ ] 阈值是否写明来源（config 键 / PLINK 默认 / 文献）？有没有"默认值"被当成"推荐值"？PASS/WARN/FAIL 是否有明确判据并传递到局限？
- [ ] 是否把"λ 正常"写成"结果可信"？是否遗漏"没做到的事"（无 LMM、无验证、5e-8 无法精确估计）？
- [ ] 分段汇报是否控制在 5–10 行、没有堆砌术语？是否给了用户下一步动作？`SUMMARY_JSON` 是否为合法单行 JSON？
- [ ] 报告是否包含复现所需的最小信息（run_id、命令、参数、种子、版本）？
