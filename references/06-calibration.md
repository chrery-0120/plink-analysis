# 仿真校准与独立重算（06-calibration）

> **适用场景**：流水线跑通之后、交付报告之前，用仿真证明"在当前样本量/位点密度下，这套 GWAS 命令没有系统性错误"，并用独立实现重算关键数字。校准回答两个问题：**零模型下会不会假阳性（λ 与经验 I 类错误）**、**有真信号时能不能检出（power、效应量、排名）**；校验回答：**PLINK 算出来的数对不对**。

## 1. 设计总览

| 组件 | 目的 | 数据 | 重复 | 验收 |
|---|---|---|---|---|
| 零模型（null） | 检验 I 类错误与 λ | 真实基因型 + 与基因型独立的表型 | R=10（流水线）/≥100（报告级） | λ 均值 ∈[0.97,1.03]；α=0.05 的经验假阳性率落在二项置信区间内 |
| 已知 QTL | 检验 power、效应量偏差、排名 | 真实基因型 + 按 h2 生成的表型 | 同上 | 因果 SNP 排名靠前；β 估计近似无偏；SE 校准 |
| 独立重算（validate） | 检验计算正确性 | 同一份数据 | 一次 | MAF/缺失率/beta/SE 等在容差内 |

原则：**校准与校验都必须复用生产环境同一条冻结命令**（同 `--bfile`、同协变量、同模型、同过滤），否则测的是另一条流水线。每次仿真的种子、样本子集、h2、因果位点列表都要落盘（`metrics.json`/`tables/`），保证可复现。

## 2. 零模型

### 2.1 表型生成

三种做法，建议按项目条件选择：

1. **置换真实表型**（推荐）：把真实表型的标签随机打乱，保持分布形状（偏态、离散、病例比例）不变，只破坏与基因型的关联。适合数量性状与二元性状。
2. **独立正态表型**：`y ~ N(0,1)`，简单但分布与真实数据不同；若真实表型强偏态，power 估计会偏乐观。
3. **病例-对照**：按原病例比例随机生成 0/1 标签（例如 30% 病例），用于检查 logistic 模型与不平衡设计。

每次重复写一个 `pheno_rep{r}.txt`（FID IID value），用同一条 GWAS 命令跑一遍，提取 `.assoc.*` 的 p 值。

### 2.2 指标

- **λGC**：λ = median(χ²)/0.4549，χ² = qchisq(1−p, 1)。均值应≈1。
- **抽样波动**：零模型下 SD(λ) ≈ 2.33/√M（M 为检验位点数）。M=6000 时约 0.03；M=50000 时约 0.010。**判断"λ 是否异常"必须带上这个尺度**，否则会把噪声当膨胀。
- **经验 I 类错误**：对每个 α∈{0.05, 1e-3, 5e-8}，统计"p<α 的位点数 / (R×M)"。α=0.05 时可用二项分布置信区间判断：R=10、M=6000 时每个重复期望 300 个假阳性，相对精度约 ±6%；α=1e-3 时每重复期望 6 个，R=10 共 60 个，相对误差约 ±13%。
- **5e-8 的特殊性**：R=10、M=6000 时期望假阳性数 = 10×6000×5e-8 = 0.003，几乎必然为 0。因此"5e-8 经验错误率"在小规模校准里**只能验证"没有出现"**，不能给出精确率；若需要精确估计，必须 R×M ≫ 2×10⁷（通常不现实），此时用 λ 与 QQ 图判断检验统计量是否校准即可。报告中要写"5e-8 水平未观察到假阳性（预期 <0.01 个），不作为 I 类错误的精确估计"。
- **QQ 图**：把 R 次重复的 p 值合并画 QQ，理论上应贴合对角线；KS 检验在 LD 存在时过于敏感（位点不独立），只作参考、不作硬门限。

### 2.3 通过标准（建议）

| 指标 | PASS | WARN | FAIL |
|---|---|---|---|
| λ 均值（R=10） | 0.97–1.03 | 0.95–0.97 或 1.03–1.05 | 超出 0.95–1.05 |
| 单次 λ 范围 | 0.94–1.06（M=6000 量级） | 0.90–0.94 或 1.06–1.10 | 超出 0.90–1.10 |
| λ 的 SD / 理论值 | 0.7–1.5 倍 | 1.5–2 倍 | >2 倍（提示位点强相关或实现问题） |
| α=0.05 经验错误率 | 在二项 95% CI 内 | 在 99% CI 内 | 超出 99% CI |
| α=1e-3 经验错误率 | 0–3 倍期望（R=10 时 0–18 个） | 3–5 倍 | >5 倍 |

注意：**λ 均值偏离 1 有两种方向**。>1.05 优先查群体结构/亲缘/表型-批次混杂/协变量不足；<0.95 优先查是否误用了 GC 校正、表型离散化过度、位点过少、p 值被截断。

## 3. 已知 QTL

### 3.1 因果位点的选择

- 数量：config `calibration.n_causal`，默认 20。
- 条件：MAF ≥0.05（保证可估计）、LD 剪枝后彼此 r²<0.1（近似独立，便于解析预期）、只用常染色体、优先从不同染色体/不同 MAF 分层抽取（避免集中在 1–2 条染色体）。
- 记录 truth 表：`snp, chr, bp, a1, af, beta_true`，写入 `04_calibration/tables/truth.csv`；所有后续指标以它为基准。

### 3.2 效应量与表型

设因果位点 j 的 A1 剂量为 g_j∈{0,1,2}（`plink --recode A`），等位基因频率 p_j，加性效应 β_j。两种生成方式：

**方式 A（等贡献，推荐用于可复现的最小校准）**

```
β_j = ± sqrt( h2 / (M · 2 p_j (1 − p_j)) )      （符号随机，或全部取正）
y_i = Σ_j β_j g_ij + ε_i ,  ε_i ~ N(0, 1 − h2)
```

此时 Var(Σβg) = h2、Var(y)=1，遗传力恰为 h2，power 的解析预期可直接算。

**方式 B（效应量随机，更接近真实遗传结构）**

```
β_j ~ N(0, h2 / (M · 2 p_j (1 − p_j)))    然后整体缩放使样本遗传方差 = h2
```

方式 B 会出现"大效应位点/小效应位点"的差异，适合检验 winner's curse 与排名指标；每次重复要重新抽 β（固定种子），并记录 β_true。

### 3.3 解析预期（用于设定验收，不靠"跑出来好看"）

单个因果位点的非中心参数近似：

```
NCP_j ≈ n · R²_j / (1 − R²_j) ,   R²_j ≈ h2 / M
power(α) ≈ Φ(√NCP_j − z_{1−α/2})
```

以 n=400、M=20（无 LD、无协变量损失、表型无误差的理想上界）为例：

| h2 | 每个 QTL 的 R² | √NCP | α=0.05 | α=1e-4 | α=1e-5 | α=5e-8 | ≥1 个 QTL 达 5e-8 |
|---|---|---|---|---|---|---|---|
| 0.5 | 0.025 | 3.20 | 0.89 | 0.25 | 0.11 | 0.012 | ≈0.22 |
| 0.3 | 0.015 | 2.47 | 0.69 | 0.08 | 0.026 | 0.0014 | ≈0.03 |

这张表说明一个容易误判的事实：**n=400、h2=0.5、20 个因果位点时，单次仿真出现全基因组显著（5e-8）的概率只有约 20%**；要求"每次都必须检出 5e-8"是不现实的验收标准（DESIGN 第 14 节的原话需按此理解）。可行的验收方式：

- 至少 1 个因果 SNP 进入 top 100（几乎必然）；
- 因果 SNP 的最小 p 值中位数 <1e-4；
- power 曲线与解析预期的偏差 <2 倍；
- 或者增大 n、减少 `n_causal`、提高 h2，再要求 5e-8 检出。

### 3.4 指标定义

- **power(α)**：R 次重复中，至少 1 个因果 SNP 的 p<α 的比例（"信号级 power"）；以及逐位点 power（每个因果 SNP 被检出的频率）。
- **效应量偏差**：对"真实因果 SNP"计算 `β_hat/β_true` 的均值（应≈1）；对"被选中的 top SNP"单独算（通常>1，即 winner's curse）。报告两者，别只报后者。
- **SE 校准**：`SD(β_hat) / mean(SE_hat)`，理想≈1；<0.8 提示 SE 高估（过于保守），>1.2 提示 SE 低估（膨胀，常见于结构/亲缘未校正）。
- **排名指标**：把所有位点按 p 值排序，计算
  - `top_causal_in_top100`：因果 SNP 落在 top 100 的比例；
  - `rank_auc`：随机取一个因果 SNP 与一个非因果 SNP，前者 p 更小的概率（Mann–Whitney AUC）。零模型下 0.5；h2=0.5、n=400 时通常 >0.95；h2=0.3 时约 0.8–0.95。
- **符号一致性**：`sign(β_hat) = sign(β_true)` 的比例（应明显 >0.5，接近 power）。

### 3.5 通过标准（建议）

| 指标 | PASS | WARN | FAIL |
|---|---|---|---|
| top_causal_in_top100（h2=0.5） | ≥0.90 | 0.7–0.9 | <0.7 |
| rank_auc（h2=0.5） | ≥0.95 | 0.85–0.95 | <0.85 |
| rank_auc（h2=0.3） | ≥0.85 | 0.7–0.85 | <0.7 |
| 因果 SNP 的 β 比值均值 | 0.9–1.1 | 0.8–0.9 或 1.1–1.2 | 超出 |
| SE 校准比 | 0.8–1.2 | 0.7–0.8 或 1.2–1.4 | 超出 |
| power(1e-4) 与解析预期 | 0.5–2 倍 | 0.33–0.5 或 2–3 倍 | 超出 |

## 4. 重复次数与随机种子

- **流水线内**：R=10（config `calibration.n_replicates`），保证 ≤15 分钟的自检预算；用于 λ 与粗 power，报告级结论需更多重复。
- **报告级**：α=0.05 的 I 类错误估计建议 R≥100（SE = √(0.05·0.95/R) ≈ 0.022）；power 估计（真值 0.5 附近）R=100 时 SE≈0.05，R=200 时 SE≈0.035。
- **种子**：由 `sha256(run_id + ":" + replicate + ":" + h2)` 派生（或固定整数表）；每个重复的种子写入 metrics，任何人都能重放。**不要用时间做种子**。
- **配对设计**：不同 h2（0.3/0.5）使用相同基因型子集与相同种子序列，减少比较噪声。
- **子集大小**：`calibration.n_snps_subset` 默认 20000；位点数越多 λ 越稳、耗时越长。报告里写清"校准在 M=… 位点、n=… 样本的子集上完成"。

## 5. 独立重算校验（validate）

目标：不用 PLINK 的同一段代码，独立算出关键量并比对。**容差是验收的一部分，必须写进报告。**

| 检查 | 参考实现 | 容差 | 常见不一致原因 |
|---|---|---|---|
| 样本/位点计数 | 直接数 `.fam`/`.bim` 行 | 完全相等 | 过滤后未用最新文件 |
| MAF | 从 `--recode A` 的 0/1/2 剂量计算 | max abs diff <1e-5 | A1 计数方向、缺失处理（分母是否含缺失） |
| 缺失率 | 从 `--recode A` 的 NA 比例 / `.imiss`/`.lmiss` | <1e-5 | 样本/位点重算顺序不同 |
| HWE p 值 | 独立精确检验实现（或 `--hardy` 与 scipy 近似对照） | 相对误差 <1e-4（或直接比 p 的 −log10 差 <1e-3） | 只算创始人、case/control 分层、mid-p |
| GWAS beta | statsmodels OLS（剂量 + 同一协变量 + 截距） | max abs diff <1e-4 | 缺失处理（逐位点 listwise）、协变量标准化、A1 方向、未加截距 |
| GWAS SE | statsmodels OLS 的 `bse` | <1e-4（相对 1e-3） | 同上；PLINK 的 t 统计量对应 `BETA/STAT` |
| logistic beta | statsmodels Logit（`beta = ln(OR)`） | <1e-4 | 完全分离、样本剔除、缺失 |
| λGC | 由 p 重算 `median(qchisq(1−p,1))/0.4549` | 与 PLINK 的 λ 差 <1e-3 | p 值被截断、使用了 GC 校正后的 p |
| PCA 特征值 | 由 GRM 独立求特征值（抽样位点） | 前 5 个特征值相对误差 <1e-3 | 位点集不同、中心化方式不同 |
| 亲缘 | 检查 `.genome` 的对称性、PI_HAT∈[0,1]、SNP_COUNT 一致 | 结构性检查 | — |
| 表型编码 | 统计取值集合与缺失数 | 与 config 一致 | 0 值歧义、BOM |

实现要点：

1. 重算 GWAS 时，**必须逐位点使用同一批样本**（PLINK 对每个位点做 listwise deletion，NMISS 会变化）；把 PLINK 的 `NMISS` 与 statsmodels 的样本数对齐。
2. 协变量要用同一个数值（不要标准化后再比）；PLINK 的 `BETA` 是 A1 剂量的系数，statsmodels 的 exog 顺序要与 A1 编码一致。
3. 二元性状用 `--logistic` 时比较 `ln(OR)` 与 Logit 系数；有完全分离的位点会得到很大 SE，先剔除或标注。
4. 抽样 20 个位点（覆盖不同 MAF 与不同染色体）即可，不必对全部位点做 statsmodels（慢）。随机抽样要固定种子并写入 metrics。
5. 校验失败时先判断是"容差太紧"还是"实现有错"：把差异按位点列出，看是否集中在特定等位基因方向/缺失模式。

## 6. 如何把校准结果写进报告

`metrics.json`（第 8 节 calibration 契约）示例：

```json
{"null":{"n_replicates":10,"lambda_mean":1.00,"lambda_sd":0.03,
         "type1":{"alpha_0.05":0.051,"alpha_1e-3":0.0009,"alpha_5e-8":0.0}},
 "power":{"h2":0.5,"n_causal":20,"alpha_5e-8":{"mean":0.2,"sd":0.4},
          "alpha_1e-4":{"mean":0.25}},
 "effect_bias":{"mean_beta_ratio":1.02,"se_calibration":0.98},
 "concordance":{"top_causal_in_top100":0.95,"rank_auc":0.97},
 "validation":{"n_checks":14,"n_pass":14,"n_warn":0,"n_fail":0},
 "overall":"pass"}
```

报告文字模板（5–8 行）：

> **校准结论**：在 n=390、M=… 的 QC 冻结数据上，用与正式 GWAS 完全相同的命令重复 10 次零模型仿真，λGC 均值 1.00（SD 0.03，理论 0.03），α=0.05 的经验假阳性率 5.1%（二项 95% CI …），未观察到 5e-8 水平假阳性（预期 0.003 个，不构成精确估计）。已知 QTL 仿真（h2=0.5、20 个因果 SNP）中，95% 的因果 SNP 进入 top 100，rank AUC=0.97，β 估计均值比为 1.02，SE 校准比 0.98，与解析预期（单 QTL 在 α=1e-4 的 power≈0.25）一致。独立重算 14 项全部通过（MAF 最大偏差 …，beta/SE 最大偏差 …）。**结论：本流水线在当前数据规模下检验统计量校准良好、效应量估计可信；全基因组显著性结论仍受样本量与芯片密度限制。**

要点：先给结论，再给数字；同时报告"没做到什么"（5e-8 的 I 类错误无法精确估计、power 的自然上限）。

## 7. 常见误区 / 检查清单

- [ ] 校准是否复用了正式的冻结命令？有没有在校准里偷偷改过滤/协变量/模型？零模型表型是否真的与基因型独立（置换后检查 p 的 QQ 是否大致均匀）？
- [ ] 是否报告了 λ 的理论抽样波动（2.33/√M）？有没有把 M=6000 时的 λ=1.08 当成膨胀？
- [ ] 是否把"5e-8 水平 0 次假阳性"误写成"5e-8 的 I 类错误为 0"？已知 QTL 的 h2 是否真的等于设定值，因果 SNP 是否彼此独立？
- [ ] power 的验收是否考虑了 n、M、h2 的解析上限？有没有用"必须 5e-8"卡 n=400 的项目？
- [ ] β 偏差是否区分了"因果 SNP"与"被选中的 top SNP"（winner's curse）？
- [ ] SE 校准比是否在 0.8–1.2？超出时是否优先怀疑结构/亲缘未校正？
- [ ] 独立重算的样本是否与 PLINK 逐位点一致（NMISS 对齐）？A1 方向、缺失、截距是否核对？
- [ ] 随机种子、子集、truth 表、容差是否都落盘，别人能否重放出同一组数字？
- [ ] 校准结论是否写进了最终报告（含"没做到"的部分），而不是只留在 logs 里？
