# 质控阈值参考（02-qc-thresholds）

> **适用场景**：为芯片或重测序数据设定 PLINK 质控阈值、解释每个阈值的科学依据、判断该放宽还是收紧。表中默认值来自 `run.json` 的 `qc` 段（DESIGN 第 4 节），**任何一项都可在 config 中修改**；报告里必须写出实际使用的值，而不是只写"已质控"。

## 2. 逐项详解

### 2.1 样本缺失率 `--mind`

- 定义：每个样本的缺失基因型比例（`--missing` 的 `.imiss` 中 `F_MISS`）。
- **顺序陷阱**：同一条 PLINK 命令里 `--mind` 在 `--geno` 之前执行（order 页），所以样本缺失率会把"马上要被 `--geno` 删掉的坏位点"算进去。正确做法是两遍：先位点过滤落盘，再 `--mind`。
- 放宽（0.10→0.20）：保留低质量样本（低覆盖、降解 DNA、劣质芯片），这些样本在 GWAS 中贡献噪声、在 PCA 中可能成为假离群。
- 收紧（0.10→0.02）：样本量小时可能删掉太多；低深度重测序（≈5×）天然缺失率高，0.02 会误删大量真实样本。
- 建议：**芯片 0.05（严格 0.02）；重测序按深度定，≥10× 用 0.05，5× 用 0.10–0.20；小群体保种项目优先用 0.10 并逐个检查原因**。
- 判定：删除的样本要输出 ID 与缺失率，报告"是否集中于某批次/某品种"——集中就是流程问题，不是样本问题。

### 2.2 位点缺失率 `--geno`

- 定义：每个位点的缺失基因型比例。
- 放宽（0.10→0.20）：保留低质量位点，会系统性压低 λ 或制造假阳性（缺失与表型/批次相关时）。可用 `--test-missing`（case/control）或 `--test-mishap` 检验缺失是否随机。
- 收紧（0.10→0.02）：高密度芯片/低深度测序会删掉大量位点（可能 >20%），降低覆盖与 power；对保种项目可能删掉稀有变异。
- 建议：**芯片 0.05（严格 0.02）；重测序 0.05；商业芯片数据 0.02–0.05**。删除比例 >10% 时必须解释原因（批次、DNA 质量、探针设计）。

### 2.3 次等位基因频率 `--maf`

- 定义：MAF 低于阈值的位点删除（`--max-maf` 可删高频位点；`--mac/--max-mac` 按等位基因计数，更适合小样本）。
- MAF 与样本量强耦合：N=100 时 MAF=0.01 只对应约 2 个拷贝，关联检验几乎没有信息；群体遗传参数（FST、ROH、MAF 谱）也要求足够多的携带者。
- 放宽（0.01→0）：保留单态/近单态位点，会让 HWE、λ 与 PCA 产生数值噪声；PLINK 对单态位点多数分析会给出缺失统计。
- 收紧（0.01→0.05）：GWAS 更稳定，但会漏掉低频因果变异；地方品种/保种群体中低频等位基因本身是保护对象，不宜一律删。
- 建议：**GWAS 0.01（N<200 时提高到 0.05）；群体结构/LD/ROH 0.01；保种多样性评估 0.01 或按 `--mac 2` 保留所有多态位点；商业纯种群体可 0.05**。
- 注意：`--maf` 在 `--hwe` 之后执行（order 页）；多品种合并数据的 MAF 高于单品种，不能拿合并 MAF 代替品种内 MAF（`--freq --within` 可分品种计算）。

### 2.4 Hardy-Weinberg 平衡 `--hwe`

- 方法：PLINK 1.9 用精确检验（Wigginton JE, Cutler DJ, Abecasis GR. *Am J Hum Genet*. 2005;76:887–893），`midp` 修饰符启用 mid-p 校正（样本量小时更少假阳性）。
- **病例-对照数据默认只在对照中检验**（`--hwe` 的默认行为），以避免"疾病相关位点偏离 HWE"被误删；需要所有样本都参与时加 `include-nonctrl`。
- 数量性状/无表型数据：对所有创始人检验。
- 阈值：1e-6 很严格（推荐用于 GWAS 前的芯片数据）；1e-4 是病例-对照 QC 的常用值；1e-3 偏松，可能保留大量分型错误。PLINK 1.9 的 `--hardy` **不会**自动按 p<0.001 过滤（与 1.07 不同），必须显式 `--hwe`。
- 放宽（1e-6→1e-4）：多保留位点，但也多保留分型错误与结构导致的偏离。
- 收紧（1e-6→1e-8）：可能删掉真实的疾病/选择位点，尤其在 case/control 中；也更容易删掉小群体中的真实偏离。
- 畜禽注意：选择、混合品种、近交、小样本都会造成真实 HWE 偏离；**不要对全部样本一刀切**。建议：按品种/群体分别看 HWE，偏离集中在某个品种或某批次 → 先查分型/批次，而不是直接删位点。

### 2.5 杂合度离群 `--het` ±3 SD

- 定义：PLINK 的 `F = (O(HOM) − E(HOM)) / (N − E(HOM))`（method-of-moments，官方 basic_stats#ibc）。F<0 表示杂合过多（污染、重复样本、混合 ancestry），F>0 表示纯合过多（近交、低覆盖导致等位基因丢失）。
- 阈值 ±3 SD（`qc.het_sd`）：正态假设下约 0.3% 双侧；但真实 F 分布常右偏（近交群体），**建议同时看稳健统计（中位数±3×MAD）并分群体判断**。
- 前提：必须在 LD 剪枝后的位点集上算；MAF 估计要可靠（样本 <50 时用 `--read-freq` 载入外部频率），否则 F 的期望值本身有偏（官方文档明确提醒）。
- 放宽：保留污染样本 → 假阳性、假近交；收紧：删掉真实的近交个体 → 保种评估低估近交，育种群体丢失家系代表性。
- 建议：双侧 ±3 SD；对"极端负 F"（杂合过多）优先怀疑样本污染/重复；对"极端正 F"先看覆盖度与近交。

### 2.6 重复与近亲 `PI_HAT`（`--genome`）

- PI_HAT = P(IBD=2) + 0.5·P(IBD=1) = Z2 + 0.5·Z1，取值范围 [0,1]。
- 判读：**>0.90 = 同一个体/单卵双生（重复样本）；0.40–0.60 = 亲子/全同胞；0.20–0.30 = 半同胞/祖孙/叔侄；<0.10 ≈ 无关**。这是理论期望值，实际受 MAF、LD、群体结构影响。
- 处理：`duplicate_pihat=0.90` 的配对 → 保留缺失率更低、表型/协变量更完整的一条；`related_pihat=0.25` 的配对 → 默认**不删**（config `remove_related=false`），交给 GWAS 解释/混合模型；用户要求独立样本时才删，并记录删了谁。
- 小群体注意：封闭保种群体即使"无关"个体也有背景 PI_HAT（0.05–0.15 常见）；阈值不能照搬人类 0.25，需看 PI_HAT 分布的低谷位置。位点数 <1000 时 PI_HAT 方差很大，结论要谨慎。
- 育种群体注意：PI_HAT 不是系谱亲缘系数；半同胞家系在低密度芯片上可能接近 0.2–0.3，全同胞可能到 0.6。报告里应同时给出系谱亲缘（若有）与基因组亲缘，二者不一致处是检查点。

### 2.7 PCA 离群

- 方法：在剪枝集上 `--pca`，用前 k 个 PC（默认 k=10）把样本投影，计算到群体中心的距离（Mahalanobis 或按 PC 标准差的欧氏距离），阈值 `pca_outlier_sd`（默认 6 SD）。
- 放宽（6→8 SD）：保留边界个体；收紧（6→4 SD）：可能把真实的地方品种/外来血统个体当离群删掉。
- **群体结构 ≠ 数据错误**：多品种/多群体数据里，PC 上的分离是生物学信号，不应删；只有"既离群又有异常缺失率/杂合度/性别"时才按错误处理。`remove_pca_outliers` 默认 `false` 就是这个原因。
- 若确需删：报告必须列出 ID、PC 坐标、离群距离，以及删除对 PCA 方差解释率的影响。

### 2.8 性别核查 `--check-sex`

- 默认阈值：女性 F<0.2、男性 F>0.8（PLINK 1.9 官方默认），基于 X 染色体 F 系数。
- 前提：X 的 PAR 已拆分（`--split-x`）、位点在近似连锁平衡（先剪枝）、MAF 估计可靠（样本少时 `--read-freq`）。官方文档给出人类 1000G 的反例：不剪枝时部分女性 F 可 >0.8。
- 放宽/收紧：阈值应通过"看 F 分布是否有明显间隙"确定，而不是机械套 0.2/0.8。哺乳动物 X 上 F 通常双峰；家禽 ZW 的杂合模式与 XY 相反，**不能用同一套阈值**。
- 处理：不一致样本先查记录错误（性别写反）→ 用 `--update-sex` 修正；查不出原因则从分析中剔除，并在报告中计数。

## 3. 场景矩阵（该放宽还是收紧）

| 场景 | mind | geno | maf | hwe | 其他要点 |
|---|---|---|---|---|---|
| 商业猪/牛/羊芯片（50K–100K） | 0.05 | 0.02–0.05 | 0.01（GWAS） | 1e-6 | LD 剪枝 50/5/0.2；PI_HAT 阈值按分布校准 |
| 商业鸡芯片（ZW） | 0.05 | 0.02–0.05 | 0.01 | 1e-6 | 只对常染色体做主分析；`--check-sex` 不适用 |
| 地方品种/保种群体（N<200） | 0.10 | 0.05 | 0.01 或 `--mac 2` | 1e-4 或只做记录 | 不轻易删近亲/离群；FROH、He、Ne 优先；HWE 偏离多为真实 |
| 多品种混合群体 | 0.05 | 0.05 | 0.01（品种内另算） | 1e-4 | 先分品种 QC，再做合并 PCA/FST；`--freq --within` |
| 重测序（≥10×） | 0.05 | 0.05 | 0.01 | 1e-6 | 注意 indel/多等位；`--biallelic-only` 或先拆分 |
| 低深度重测序（≈5×） | 0.10–0.20 | 0.10–0.20 | 0.01（用基因型概率需专门工具） | 1e-6 | 基因型不确定性大，PLINK 硬调用结果偏保守；建议 imputation 后再分析 |
| 病例-对照 | 0.05 | 0.02 | 0.01 | **只在对照中 <1e-4** | 加 `--test-missing` 检查差异缺失；HWE 在病例中偏离可能是真实信号 |
| 数量性状 | 0.05 | 0.02–0.05 | 0.01 | 1e-6（全部样本） | 表型需检查分布/异常值；性别作为协变量 |

## 4. 过滤顺序与理由（与 `01-pipeline-stages.md` 第 8 节对应）

推荐顺序：**位点（缺失率→HWE→MAF）→ 样本（缺失率）→ 剪枝 → 性别/杂合度/亲缘/PCA → 冻结**。

理由：

1. 先删坏位点，避免它们污染样本缺失率与杂合度估计；同一条命令里 `--mind` 在 `--geno` 前，所以必须分步落盘。
2. HWE 在 MAF 之前：MAF 过滤会改变 HWE 检验的位点集（虽然不影响单点 p），PLINK 的实际顺序是 `--geno → --hwe → --maf`，与"先删缺失、再删偏离、最后按频率"的直觉一致。
3. LD 剪枝放在估计类计算之前：`--pca`、`--genome`、`--het`、`--ibc`、`--fst` 全局均值都假设位点近似独立（官方文档对每个命令都有此提醒）。
4. 性别核查放在剪枝之后、PCA 之前：不一致性别会扭曲 X 上的 F 与 PCA；先修再算。
5. 最后冻结：后续 popgen/GWAS 只读 `qc_final`，不再改过滤；任何变化都要重跑整个流程（保证可复现）。

## 5. 放宽/收紧的后果速查

| 操作 | 直接后果 | 可观察信号 | 何时可以接受 |
|---|---|---|---|
| mind 放宽 | 保留低质量样本 | 缺失率分布长尾、PCA 边缘点、λ 轻微下降或假阳性 | 低深度测序、小群体 |
| mind 收紧 | 样本量下降 | 保留率骤降、某批次被清空 | 芯片高质量数据、样本充足 |
| geno 放宽 | 保留坏位点 | 缺失与批次/表型相关、HWE 异常 | 位点稀少、保种稀有变异 |
| geno 收紧 | 位点数下降 | 保留率 <70%、覆盖不均 | 高密度芯片、imputation 前 |
| maf 放宽 | 更多低频位点 | MAF 谱左移、λ 不稳、PCA 噪声 | 群体参数/保种分析 |
| maf 收紧 | 位点数下降 | 低频因果变异丢失、power 下降 | GWAS 稳定优先 |
| hwe 放宽 | 保留偏离位点 | HWE QQ 尾部厚、λ 升高 | 小群体/选择群体（需说明） |
| hwe 收紧 | 删真实位点风险 | 病例-对照中关联信号减少 | 分型质量差的数据 |
| het SD 放宽 | 保留污染/近交个体 | F 分布尾部、PCA 离群重合 | 近交群体（改用稳健统计） |
| PI_HAT 收紧 | 删除更多亲属 | 样本量骤降、家系代表性丢失 | 明确要求独立样本 |

## 6. 常见误区 / 检查清单

- [ ] 是否按 PLINK 的实际顺序执行（`--mind` 先于 `--geno`，`--hwe` 先于 `--maf`）？样本缺失率是否在过滤后的位点集上重算？
- [ ] case/control 的 HWE 是否只在对照中检验？有没有误把病例的偏离当成质量问题进行删除？
- [ ] 地方品种/小群体的 HWE 偏离是否先归因于选择/混合/近交，而不是直接判为分型错误？
- [ ] `--het` 是否在剪枝集上算？样本量小（<50）时是否用 `--read-freq` 提供可靠 MAF？
- [ ] PI_HAT 阈值是否根据本群体分布校准？有没有把"家系群体中的真实亲属"当重复样本删掉？
- [ ] PCA 离群是否与品种/血统分离混为一谈？删除离群是否在报告中给出 ID 与理由？
- [ ] 性别核查是否在 X 剪枝后做？PAR 是否处理？家禽是否误用 XY 阈值？
- [ ] 所有阈值是否写进报告与 `metrics.json`（而不是只出现在命令行历史里）？
- [ ] 过滤前后的样本数/位点数是否都能对上（in − removed = out）？
- [ ] 有没有因为"想得到显著结果"而反向调整阈值？任何阈值调整都必须有预先声明的理由，并做敏感性分析（例如 maf 0.01 vs 0.05 各跑一次，比较 lead SNP 稳定性）。
